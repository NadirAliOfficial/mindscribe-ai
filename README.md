# Text Enhancer

AI-powered text improvement Chrome extension — rewrites and enhances selected text on any website using a local Ollama LLM.

## Features
- Right-click context menu integration
- Multiple enhancement modes: formal, concise, creative
- Local AI (Ollama) — no data sent to external servers
- Works on any input field or text area

## Installation
1. Clone this repo
2. Open `chrome://extensions/`
3. Enable Developer Mode → Load unpacked → select this folder
4. Make sure Ollama is running locally: `ollama serve`
